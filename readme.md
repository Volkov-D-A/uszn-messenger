Кроссплатформенный рабочий месенджер для небольшой организации в современном стиле (mattermost, rocketchat, discord). Основные возможности:
1. Личные и групповые чаты. Групповые чаты подразделений, а также тематические для межведомственных задач.
2. История сообщений.
3. Возможность отправки в чат файлов (документов, изображений), файлы временно хранятся на сервере.
4. Возможность указания своего текущего статуса (занят, отошел и пр.).
5. Возможность включения режима "Не беспокоить".
6. Отдельный канал для массового уведомления сотрудников о важных событиях с индикацией.
7. Офлайн отправка сообщений
8. Трехпанельная компоновка: слева список активных чатов, посередине текущий чат, справа доступные чаты и контакты
9. Профиль пользователя

Технологический стек:
1. Десктоп приложение wails + react
2. Сервер GO + Postgres + Minio + Caddy + Seq
