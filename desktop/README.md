# USZN Messenger — UX-прототип

Desktop-прототип этапа 1 на Wails v2, React и TypeScript. Он использует только детерминированные мок-данные, не обращается к серверу и не доказывает готовность сетевого или security-контура.

## Запуск

Требования: Go, Node.js/npm, Wails v2 и системные библиотеки WebKit2GTK ABI 4.1.

```bash
cd desktop
wails dev -tags webkit2_41
```

Production-сборка для Ubuntu 22.04 x64:

```bash
wails build -tags webkit2_41
```

Проверка frontend отдельно:

```bash
cd desktop/frontend
npm run build
```

## Реализованный первый срез

- трёхпанельная desktop-компоновка со сворачиваемой правой панелью;
- список личных, публичных, приватных и служебных чатов;
- история, упоминание, критичная карточка и подтверждение «Ознакомлен»;
- отправка текста, явное состояние офлайн-очереди и восстановление без визуального дубликата;
- раздел «Внимание» с переходом к исходному контексту;
- переключение ролей, скрытие административных действий и право на критичность;
- тёмная/светлая темы и панель детерминированных сценариев.

Это основа сценариев 1, 5, 7, 8 и 9 из UX-спецификации, но они ещё не отмечаются принятыми целиком. Следующие срезы должны добавить полный набор действий над сообщением, вложения, объявления, DND/автоответ, настройки уведомлений и административные формы.
