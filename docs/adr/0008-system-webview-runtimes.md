# ADR-0008: Системные WebView runtime и параметры сборки

- Статус: Принято
- Дата: 2026-07-28

## Контекст

Wails использует Microsoft WebView2 на Windows и WebKit2GTK на Linux. Включение фиксированного WebView2 в каждый Windows-релиз увеличивает объем поставки, а поддержка нескольких ABI WebKitGTK усложняет Linux-сборку.

## Решение

Windows 10/11 x64 собирать стандартной командой Wails v2 `wails build -platform windows/amd64`. Использовать системный WebView2, не включая фиксированный runtime в комплект клиента. Стандартная стратегия Wails при отсутствии runtime — предложение загрузки; в изолированном контуре она не сработает, поэтому наличие WebView2 обеспечивается базовым образом Windows.

Ubuntu 22.04 x64 собирать командой `wails build -platform linux/amd64 -tags webkit2_41`. Использовать системные GTK3 и WebKit2GTK ABI 4.1. Конкретные patch-версии WebView2 и WebKit2GTK не фиксировать; для каждого клиентского релиза записывать и испытывать фактические версии в матрице совместимости.

Точную версию Wails v2 фиксировать в `go.mod` и manifest каждого клиентского релиза; «стандартная сборка» означает стандартные параметры именно этой зафиксированной версии.

## Последствия

- Размер клиентского релиза не увеличивается за счет WebView runtime.
- Обновление и защита runtime относятся к базовому образу рабочей станции.
- Windows-клиент не запустится автономно на рабочем месте без WebView2; стандартная попытка загрузки не поможет в изолированном контуре.
- Linux-клиент совместим только с ABI WebKit2GTK 4.1 и не поддерживает систему только с ABI 4.0.
- Разные patch-версии runtime могут различаться поведением, поэтому матрица испытаний обязательна для каждого релиза.
