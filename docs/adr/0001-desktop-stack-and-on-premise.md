# ADR-0001: Desktop-стек и автономное развертывание

- Статус: Принято
- Дата: 2026-07-24

## Контекст

Нужен единый современный desktop-интерфейс для Windows 10/11 и Ubuntu 22.04 в сети без интернета. Web, mobile и macOS не входят в объем.

## Решение

Использовать Wails v2 с React/TypeScript для клиента и Go для клиентского ядра и сервера. Сервер поставлять Docker Compose-комплектом для Linux; все ресурсы и runtime-зависимости переносить в автономный контур.

## Последствия

- UI и типы переиспользуются между целевыми ОС.
- Windows требует контролируемого наличия WebView2, Ubuntu — GTK3/WebKitGTK.
- Для каждой ОС нужна отдельная сборка и E2E-матрица.
- Добавление другой ОС требует отдельного решения и приемочных испытаний.
