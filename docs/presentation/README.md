# Презентация для руководства

Комплект предназначен для обсуждения на уровне руководства вопроса о создании и внедрении внутренней системы коммуникации УСЗН.

Актуальная версия состоит из девяти слайдов в формате PNG и сосредоточена на преимуществах нового приложения:

1. **Недостатки текущего приложения.** Множество отдельных окон, сложный поиск нужного диалога, ограниченные групповые обсуждения и уведомления; сообщения могут потеряться.
2. **Все рабочие коммуникации в одном окне.** Личные сообщения, групповые чаты, объявления и переписка подразделений собраны в едином пространстве.
3. **Быстрая связь с нужными сотрудниками.** Чаты подразделений, служебные группы и адресные объявления помогают сразу обратиться к нужной аудитории.
4. **Важная информация не останется незамеченной.** Непрочитанные сообщения, упоминания, закрепления и подтверждение ознакомления помогают контролировать важные поручения и объявления.
5. **Уведомления под контролем пользователя.** Для каждого чата можно получать уведомления обо всех сообщениях, только об упоминаниях или отключить обычные уведомления, не рискуя пропустить критичную информацию.
6. **Всё, что требует внимания, — в одном разделе.** Упоминания, непрочитанные критичные сообщения и объявления, ожидающие ознакомления, собраны в едином персональном списке с переходом к исходному контексту.
7. **Удобный обмен файлами и поиск сообщений.** Документы и изображения можно передавать прямо в чатах. Тексты доступны бессрочно, а файлы — в течение 30 дней после отправки.
8. **Дизайн-макет нового приложения.** Единый экран со списком чатов, разделом «Внимание», объявлениями, текущей перепиской, вложениями, сотрудниками и их статусами.
9. **Итог: удобнее общаться — проще работать.** Новое приложение сокращает количество лишних действий, ускоряет координацию и снижает риск пропустить важную информацию.

Все девять слайдов этой редакции подготовлены.

Готовый комплект: [sistema-kommunikacii-uszn.pdf](sistema-kommunikacii-uszn.pdf).

Дополнительные материалы:

- `speaker-notes.md` — тезисы выступления по каждому слайду;
- `slides/*.html` — редактируемые исходники актуальных слайдов;
- `slides/*.png` — готовые изображения размером 1920 × 1080;
- `assets/` — фоновые иллюстрации;
- `sistema-kommunikacii-uszn.pptx` и `generate-presentation.js` — ранний черновик презентации PowerPoint, сохранённый для истории.

Презентация намеренно не содержит подробностей внутреннего устройства программы, этапов разработки и финансовых оценок без исходных данных.

## Пересборка актуальных слайдов

Для преобразования HTML в PNG используется `slides/render-slide.js`, Node.js и Puppeteer. Путь к HTML и выходному PNG передаются аргументами:

```bash
node docs/presentation/slides/render-slide.js \
  docs/presentation/slides/01-title.html \
  docs/presentation/slides/01-title.png
```

Итоговый PDF собирается из девяти PNG после визуальной проверки текста и порядка слайдов:

```bash
node docs/presentation/slides/build-pdf.js
```
