# Открытые вопросы и журнал решений

Этот реестр содержит только решения, которые нельзя безопасно оставить на усмотрение реализации. Рекомендуемый вариант — исходная точка обсуждения, а не автоматически принятое требование.

## Открытые вопросы

Открытых вопросов нет. Новые вопросы добавляются в этот раздел по мере появления.
