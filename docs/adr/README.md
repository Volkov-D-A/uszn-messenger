# Architecture Decision Records

ADR фиксируют контекст и последствия ключевых решений. Статусы: `Принято`, `Частично заменено`, `Заменено`, `Отклонено`. Принятый ADR не редактируется для изменения смысла; новое решение ссылается на старое и заменяет его.

| --- | --- | --- |

| [0002](0002-modular-monolith.md) | Модульный Go-монолит без брокера | Принято |
| [0003](0003-rest-websocket-sync.md) | REST, WebSocket, журнал событий и идемпотентность | Принято |
| [0004](0004-server-readable-content.md) | Серверно-читаемый контент без E2EE | Принято |
| [0005](0005-smb-launcher-local-cache.md) | SMB-launcher и локальный versioned-кеш | Частично заменено ADR-0006 |
| [0006](0006-unsigned-client-releases.md) | Клиентские релизы без криптографической подписи | Принято |
| [0007](0007-embedded-internal-ca.md) | Встроенный публичный сертификат внутреннего CA | Принято |
