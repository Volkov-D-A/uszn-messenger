# Презентация для руководства

Комплект предназначен для обсуждения на уровне руководства вопроса о создании и внедрении внутренней системы коммуникации УСЗН.

Актуальная версия состоит из пяти слайдов в формате PNG:

1. Текущая ситуация: система обмена уже есть, но множество окон мешает работе.
2. Предлагаемое решение: единое окно для рабочих сообщений.
3. Основные возможности сотрудников.
4. Примерный внешний вид системы.
5. Результат внедрения для организации.

Дополнительные материалы:

- `speaker-notes.md` — тезисы выступления по каждому слайду;
- `slides/*.html` — редактируемые исходники актуальных слайдов;
- `slides/*.png` — готовые изображения размером 1920 × 1080;
- `assets/` — фоновые иллюстрации;
- `sistema-kommunikacii-uszn.pptx` и `generate-presentation.js` — ранний черновик презентации PowerPoint, сохранённый для истории.

Презентация намеренно не содержит подробностей внутреннего устройства программы, этапов разработки и финансовых оценок без исходных данных. Подтверждение прочтения упоминается только как возможное дальнейшее расширение.

## Пересборка актуальных слайдов

Для преобразования HTML в PNG используется `slides/render-slide.js`, Node.js и Puppeteer. Путь к HTML и выходному PNG передаются аргументами:

```bash
node docs/presentation/slides/render-slide.js \
  docs/presentation/slides/01-title.html \
  docs/presentation/slides/01-title.png
```

Итоговый PDF собирается из пяти PNG после визуальной проверки текста и порядка слайдов.
