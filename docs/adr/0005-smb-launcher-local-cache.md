# ADR-0005: SMB-launcher и локальный versioned-кеш

- Статус: Частично заменено ADR-0006 в части обязательной подписи manifest
- Дата: 2026-07-24

## Контекст

Администратор хочет централизованно заменять клиент на удаленном сервере. Прямой запуск рабочего бинарника с SMB создает блокировки обновления и зависимость работы приложения от доступности общей папки.

## Решение

Пользователь запускает небольшой launcher с SMB. Он проверяет подписанный manifest, копирует подходящий клиент в локальный versioned-кеш и запускает локальную копию. Сохраняются текущая и предыдущая проверенные версии.

## Последствия

- Центральный релиз можно обновлять при работающих клиентах.
- Недоступность SMB не мешает запуску последней совместимой версии.
- Нужны подпись manifest, checksum, атомарная активация и правила совместимости клиента/сервера.
- На рабочей станции остается локальная копия, которую требуется учитывать в политике диска и очистки.
