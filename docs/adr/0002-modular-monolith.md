# ADR-0002: Модульный Go-монолит без брокера сообщений

- Статус: Принято
- Дата: 2026-07-24

## Контекст

Одна инсталляция обслуживает до 500 пользователей и 200 одновременных соединений. Изолированный контур должен оставаться простым в развертывании и восстановлении.

## Решение

Реализовать один серверный Go-бинарник с модульными границами. Использовать PostgreSQL для бизнес-данных, блокировок фоновых задач и транзакционного outbox. Не вводить Redis, NATS или Kafka до появления измеренной необходимости.

## Последствия

- Меньше компонентов, резервных процедур и отказов конфигурации.
- Транзакционная целостность проще, чем при раннем разделении сервисов.
- Горизонтальное масштабирование потребует нового ADR и внешней маршрутизации событий.
- Границы модулей должны проверяться архитектурными тестами, чтобы монолит не стал неструктурированным.
